# web: Kasauti console

Next.js console for the clinic receptionist and Kasauti: service status, clinic data,
talking to the agent (Day 4) and Kasauti results (week 2 onward).

```bash
nvm use            # Node 22
npm install
npm run dev        # http://localhost:3000
```

Reads `NEXT_PUBLIC_CLINIC_API_URL` and `NEXT_PUBLIC_VOICE_AGENT_URL` (defaults: :8000, :7860).
